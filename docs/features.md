# 功能与数据说明

本页补充 [README](../README.md) 的使用细节，描述当前版本行为。

## 工作区与首页

顶部折叠条点击展开。macOS 折叠条宽 200px，高度跟随菜单栏；Windows 为 200 × 38 DIP，避开任务栏。默认展开首页，可在「设置 → 默认展开页」选择当前可见页面；隐藏所选页面后回退首页。

首页在 macOS 有番茄钟、当前窗口、快速录音、随笔记、常用指令、AI 新闻六个组件，Windows 不显示当前窗口。隐藏不删除数据，剩余组件自动填满；至少保留一个。录音中不能隐藏正在显示的录音卡，已隐藏卡片不影响「录制」页；隐藏当前窗口停止扫描，番茄钟继续计时和提醒。

AI 新闻有独立页面与首页组件开关。AI 用量是与 AI 新闻相邻的可选工作区页面，默认关闭；旧首页用量卡已启用时迁移为页面启用，手动关闭后不会反复开启。剪贴板也默认关闭，可从设置或菜单启用。

## 待办、笔记、链接与录音

待办有四个可重命名分类。默认截止当天 23:30，跨天或睡眠唤醒后刷新默认值；当前草稿手选的日期保留，提交后恢复当天默认。按截止时间排序，到期前一小时提醒。脚本导入见 [待办收件箱](todo-inbox.md)。

首页随笔支持 Markdown，保存后进入笔记页，可搜索、重命名、编辑和删除。链接保存公开网址，抓取标题与图标，可用 AI 辅助命名和分组。凭据管理使用系统加密；剪贴板图片单独保存为文件，不塞进 LocalStorage。

录音由用户主动开始，支持暂停、继续与结束；结束或退出时释放麦克风。百炼实时转写是可选功能。连接中断会保留文字并重连，连续失败最多重试 5 次，最多缓存最近 30 秒音频。本地录音继续；未确认音频和超出缓存的片段可能缺字，不自动补转旧录音。

## AI 服务与网络边界

配置按供应商 → 凭据 → 任务分配进行。新闻翻译、命名与分组、实时语音独立选连接与模型，或明确关闭。读取模型列表只验证该请求；手动模型标记未测试，推荐只填空项，不覆盖显式关闭。文本适配 OpenAI 兼容、Anthropic Messages 与 Gemini；本地 Ollama 可单独连接。语音目前仅有百炼 `qwen3-asr-flash-realtime` 适配，模型列在清单中不代表支持转写。

新闻列表从固定 AIHOT 接口获取；图文原文使用匿名隔离请求，逐跳检查地址、限制大小与时间，解析为文字及内嵌图片，不执行远端 HTML、脚本或指令。来源不公开时显示失败或部分内容。原文和译文只有限缓存，收藏与保存笔记保存摘要和链接。

主动翻译时发送已取得的标题、段落、列表、图片说明，不发送图片文件；命名与分组发送相应待命名内容；启用语音转写时音频发送至所选百炼服务。余额查询发送相应平台凭据。模型调用、余额与新闻服务遵循各自服务方规则。

## AI 用量与账单

余额只接入 DeepSeek 官方与 Moonshot 国内端点，未支持的平台不显示假余额。页面可见时至少间隔 60 秒刷新，错误保留旧值并注明。不同连接可能属于同一账户，界面不自动合并；币种分开查看。

DeepSeek 在官网按日期与「API Key 全部」导出 ZIP，包含费用与用量两张 CSV。在应用中选账户、选文件、核对预览日期和总量后确认。其他平台可映射 CSV 字段，至少要有日期和一项指标。导入的同账户、同类别（费用 / 用量）、同币种重叠范围替换旧范围，避免重复计算。局部 Key 导出不能充当完整账户数据；费用没有 Key 归属时，按 Key 筛选不推算费用。

支持今日、近 7 天、近 30 天、自定义日期，以及模型和 Key 筛选。范围不完整时标明部分；未提供指标显示未知。已导入消费只代表导入覆盖范围，不是账户终身累计。更新要重新导出导入，不抓取平台 Cookie 或未公开账单接口。

本程序调用统计在底部独立展示，只使用本程序文本调用真实返回的数量，不加到账户账单；未报告用量时明确标注。按本机日期保存到 `ai-usage.json`，保留最近 365 天，不含正文或密钥。语音、其他软件和升级前历史不在其中。

## 本地数据与迁移

工作区包含 `workspace.json`、`recordings/` 与 `clipboard-images/` 等内容，媒体用相对路径。API 配置和凭据由主进程系统安全存储处理，不向界面回传保存的明文。账单仅主进程本地解析，持久化文件 `ai-account-usage.json` 保存规范统计、覆盖范围与掩码 / 散列标识，不保存原始正文、用户 ID 或明文 Key。源文件由用户自行保管。

更换连接凭据、地址、供应商或协议会形成新的账户身份；旧账单仍可作为已导入账户查看，不会关联到新余额。普通工作区可复制迁移，但系统加密数据不保证跨设备、系统用户或应用身份解密。

## 本机任务完成提醒

只监听 `127.0.0.1:43821`，来源限 `codex`、`claude`、`gpt`。提醒是 400 × 96 的无焦点窗口；子代理结束和云端会话不弹提醒。Windows 提醒不支持点击切回任务窗口。

```bash
curl -X POST http://127.0.0.1:43821/notify/codex \
  -H 'Content-Type: application/json' \
  -d '{"title":"任务已完成","project":"example","task_id":"demo"}'
```

转发脚本见 [codex-notify.js](../scripts/codex-notify.js) 与 [claude-notify.js](../scripts/claude-notify.js)。macOS 安装后位于 `/Applications/醒目-个人效率工作台.app/Contents/Resources/app/scripts/`；Windows 位于安装目录的 `resources/app/scripts/`。
