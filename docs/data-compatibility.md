# 数据与兼容说明

醒目将工作区资料保存在本机。可在「设置 → 数据文件夹」查看或更换位置。

## 已有用户

为兼容已有本机资料与 macOS 钥匙串，内部应用名和数据目录标识保持稳定，显示名称为「醒目」。更新时不需要手动迁移待办、笔记或设置。

## 开发者配置

- 默认数据目录：`~/Library/Application Support/TO-DO Panel 二开版`
- 内部应用名：`TO-DO Panel 二开版`
- Bundle ID：`com.dynamicpanel.app.custom`
- 本机通知端口：`127.0.0.1:43822`

显示名称与内部标识分开维护；修改内部名称可能影响已有数据与钥匙串访问。请勿同时运行使用相同标识的多个应用副本。
