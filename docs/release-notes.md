# 醒目-个人效率工作台 v2.0.0

全新的浅色桌面工作台，整合待办、笔记、链接、录音、AI 新闻和账户用量。

## 本次更新

- 暖白界面与黑色顶部折叠条；首页实用组件可按需显示，工作区页面与默认页可设置。
- AI 新闻支持收藏、分页、图文原文、摘要保存与按需中文翻译，部分正文明确标注。
- 多供应商 API 连接，翻译、命名与分组、实时语音分别选择模型或关闭。
- 可选 AI 用量独立页：DeepSeek / Moonshot 国内端点余额、DeepSeek 官方导出 ZIP 与 CSV 账单导入、日期筛选和模型 / Key 明细。
- 账户账单与本程序调用统计分开展示；不同币种不混算，缺失数据不伪造为零。
- 保留系统加密、本地工作区、待办文件收件箱与本机任务完成提醒。

## 下载

- `Xingmu-2.0.0-arm64.dmg`：macOS 13+，Apple Silicon。
- `Xingmu-2.0.0-windows-x64-setup.exe`：Windows 10 / 11，x64。
- 两个安装包均提供对应 `.sha256` 校验文件。

macOS 使用 ad-hoc 签名，未做 Apple 公证；Windows 暂无商业代码签名。系统可能提示确认来源，请核对下载来源和校验文件。Windows 不提供 macOS 当前窗口组件，剪贴板点击复制后由用户粘贴。

## 升级与数据

先退出旧版。首次启动将旧版默认数据目录复制到新的应用目录，原目录保留，已有新目录不覆盖。API Key 可能需要重填；系统权限和开机自启需重新确认，并停用旧版登录项以免双开。

账户消费来自用户导入的账单范围，不代表全厂商自动历史，也不等于开户以来累计消费。读取模型列表不等于实际调用已验证，AI 调用按对应服务规则计费。新闻及其他第三方接口须遵循服务方条款。
