# ADR-0002：首页固定网格与原子显隐

状态：采用，按 v2.0.0 更新。

## 背景

首页为固定 12 × 4 网格。macOS 当前六个组件：番茄钟、当前窗口、快速录音、随笔记、常用指令、AI 新闻；Windows 隐藏不支持的当前窗口。AI 用量使用独立工作区页面，不占首页。

## 决策

- 隐藏 ID 保存在 `notch-home-hidden-modules-v1`，过滤不存在的组件，保留已有排列与业务数据。至少保留一个可见组件。
- 全部六组件可见时保留尺寸偏好与打包布局；隐藏组件或平台能力受限时使用有限模板填满 48 格，关闭没有实际效果的尺寸按钮。
- 布局提交前校验组件集合、整数坐标、边界、交叠和完整覆盖；失败保持原状态或进入可恢复的安全布局，不覆盖有效存储。
- 显隐使用同步事务：计算、验证、生命周期调整、提交 DOM/内存、持久化与事件。动画不延迟状态提交；快速切换取消旧动画，减少动效模式跳过过渡。
- 隐藏当前窗口停止扫描；番茄钟继续业务计时；活动录音不能从可见改为隐藏，隐藏录音卡不会禁用录制页。
- 旧首页用量卡启用状态迁移到可选工作区页面；完成标记避免用户手动关闭后再次启用。迁移异步结果不得覆盖较新的设置。

## 代价与验证

有限模板牺牲任意尺寸自由度，换取固定组件集的确定性和完整覆盖。每个组件仍须适配紧凑布局。测试应覆盖六组件的所有非空显隐组合、平台差异、保存失败、过期迁移响应、标准与窄屏内容边界。

相关实现：`renderer/domain.js`、`renderer/app.js`、`renderer/workspace.js`；产品行为见 [README](../../README.md)。
