# 开发流程

1. 阅读 [README](../README.md)、[AGENTS](../AGENTS.md) 和相关模块，确认当前行为及数据兼容边界。
2. 使用 Node.js 22.13.0+，根目录 `npm ci`。普通桌面开发运行 `npm start`，没有独立 renderer 构建步骤。
3. 修改相关实现和必要测试。网络使用离线 fixture；集成测试使用临时数据目录，不触碰用户凭据或工作区。
4. 先运行关联 Node 测试或语法检查；功能完成后运行 `npm test`，再核对真实 UI、窄屏、关闭/重新打开与旧数据迁移。
5. 官网在 `website/` 单独运行 `npm test`、`npm run lint`、`npm run build`。不要把官网构建结果当作桌面端验收。
6. 有发布授权时按 [发布流程](releasing.md) 生成并校验安装包。推送源码、Actions 成功、Release 资产可下载及网站下载按钮正确是不同检查点。

多人并行时明确文件所有权；串行运行 Electron 测试，避免争抢焦点。保留用户未提交的改动与原始数据，清理历史资料时移到仓库外备份，不将本地备份发布。
