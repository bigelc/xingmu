# 醒目-个人效率工作台

一个常驻屏幕顶部的本地桌面工作台，把待办、笔记、录音、AI 新闻与 AI 用量放在一起。点击顶部黑色折叠条展开，使用暖白、灰色卡片与少量蓝色强调的工作界面。

当前稳定版本：**2.0.0** · [下载最新版](https://github.com/bigelc/xingmu/releases/latest) · [更新记录](CHANGELOG.md)

## 下载与安装

| 平台 | 系统要求 | 安装包 |
| --- | --- | --- |
| macOS | macOS 13+，Apple Silicon | `Xingmu-2.0.0-arm64.dmg` |
| Windows | Windows 10 / 11，x64 | `Xingmu-2.0.0-windows-x64-setup.exe` |

从 [GitHub Releases](https://github.com/bigelc/xingmu/releases/latest) 下载对应安装包，并按发布页提供的 SHA-256 校验文件核对。macOS 将应用拖入「应用程序」；Windows 运行安装程序。当前安装包没有 Apple 公证或商业代码签名，系统可能提示确认来源。Windows 卸载默认保留用户数据。

### 从 v1 升级

请先退出旧版，再启动 v2。首次启动会把旧版默认数据目录复制到新的「醒目-个人效率工作台」目录；原目录保留，已有的新目录不会被覆盖。自选工作区继续使用原路径。

应用身份变化后，系统加密的 API Key 可能需要重新填写；辅助功能、屏幕录制权限与开机自启请在 v2 或系统设置中重新确认。停用旧版登录项，避免两个版本同时启动。升级前可自行备份工作区。

## 主要功能

| 功能 | 当前支持 |
| --- | --- |
| 首页 | 番茄钟、当前窗口、快速录音、随笔记、常用指令、AI 新闻；组件可排序、调整与隐藏 |
| 待办 | 四个可重命名分类、截止时间、排序、到期前提醒，以及本地 JSON 收件箱导入 |
| 笔记与链接 | 随笔保存、搜索、编辑与管理；可选 AI 命名和分组 |
| 录音 | 本地录音、暂停、继续与保存；可选百炼实时语音转写 |
| AI 新闻 | AIHOT 资讯、收藏、保存摘要、图文原文阅读与按需中文翻译 |
| AI 服务 | 多供应商连接；新闻翻译、命名与分组、实时语音分别选择模型或关闭 |
| AI 用量 | 可选独立页面：支持的平台余额、官方导出账单导入、日期筛选、模型与 Key 明细 |
| 密钥与剪贴板 | 系统加密保存凭据；剪贴板历史默认关闭，可在设置中启用 |
| 桌面交互 | 默认页、快捷键、工作区目录、开机启动，以及本机 AI 工具任务完成提醒 |

Windows 不提供 macOS 当前窗口组件；剪贴板点击后复制，再由用户粘贴。首页至少保留一个组件，隐藏不会删除对应数据。旧布局中的镜子、音乐组件会被过滤。

### AI 新闻与翻译

新闻首批显示 5 条，每次加载更多 5 条，收藏列表不分页。原文以纯文本和内嵌图片显示，不执行新闻网页脚本。公开来源可能只返回摘要或部分长文；界面会明确标注，并提供重新获取。登录、付费或访问验证页面不会被绕过。保存笔记保存的是摘要和来源链接。

翻译由用户主动发起，使用所选模型；发送正文、标题和图片说明，不上传图片文件，不进行 OCR。可切回原文并保留阅读位置。第三方模型可能收费，读取模型列表不代表实际调用已验证；手动添加的模型会标注未测试。目前实时语音仅支持已有的百炼适配。

新闻来自 [AIHOT](https://aihot.news/)。使用第三方内容和接口须遵循其服务条款；本项目开源许可不代表已取得内容或接口的商业授权。

### AI 用量的数据口径

- **账户余额**：目前自动读取 DeepSeek 官方与 Moonshot 国内端点的余额。其他供应商、自定义端点及订阅额度不假装已接入；各账户和币种分开显示。
- **账户消费**：从用户选择的官方导出文件导入。DeepSeek ZIP 的 `cost` / `amount` 两张表可自动识别，其他 CSV 可映射字段。预览日期、金额、请求和 Token 后确认导入；重复或重叠范围按账户、数据类别和币种处理，避免重复累计。
- **范围与缺失**：导入范围内的消费不等于开户以来的累计消费。未覆盖的数据保持未知；费用文件没有 Key 维度时，不推算某个 Key 的消费。完整账户统计应导出全部 API Key，部分导出不能冒充完整账户。
- **本程序统计**：在页面底部单独展示，只统计本程序文本模型调用返回的用量。它不包含其他软件、旧历史或实时语音；供应商未返回用量时标记未报告，不伪造为 0。

余额刷新只在页面可见时进行，间隔至少 60 秒；失败保留旧值并注明。账单更新需要重新导入。本项目不读取平台 Cookie，也不自动抓取各厂商的完整账单。更换连接凭据后，旧账单保留为独立的已导入账户，不与新账户余额混合。

## 数据与隐私

业务数据主要保存在本机，支持选择工作区文件夹；录音与剪贴板图片使用相对路径。默认数据目录为 macOS 的 `~/Library/Application Support/醒目-个人效率工作台/` 或 Windows 的 `%APPDATA%\醒目-个人效率工作台\`。

API Key 与密钥通过系统安全存储加密，界面读取配置不会得到明文 Key。账单在主进程中本地解析，仅保存规范统计、覆盖日期和掩码/散列标识，不保存原始账单正文、用户 ID 或明文 Key。系统加密数据不保证跨设备、系统账户或应用身份直接迁移。

本项目没有自建云同步服务。新闻、链接信息、余额查询和用户启用的 AI 调用会访问对应外部服务；内容发送范围见 [功能与数据说明](docs/features.md)。请勿把用户数据、账单、录音、API Key 或本地配置提交到公开仓库。

## 开发

需要 Node.js **22.13.0+**。桌面端使用 Electron 44 与原生 HTML/CSS/JavaScript。

```bash
npm ci
npm test
npm start
```

`npm test` 包含 Node 单元测试、隔离数据目录的 Electron 集成测试与语法检查。测试通过不等于已完成两个平台的真实安装验收。

```bash
npm run pack       # 生成应用目录
npm run build      # macOS arm64 DMG
npm run build:win  # Windows x64 NSIS 安装包
```

官网位于 `website/`，使用 React 19 / Vinext；在该目录执行 `npm ci`、`npm run dev`、`npm run lint` 或 `npm run build`。
