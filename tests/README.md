# 测试范围

本次发布对应当前已安装的醒目运行时快照。测试文件沿用已有测试，仅将通知测试中的作者本机路径和对应项目名换成通用示例。未为了通过测试改动应用逻辑或测试预期行为。

执行 `npm test`，包含以下 64 项 Node 测试以及 18 个运行时 JavaScript 文件的语法检查。发布前在 Node v26.8.1 上验证通过，失败 0、跳过 0。

## 版本适配说明

开发目录包含晚于已安装版的功能改动，不能把全部开发测试直接用于本次快照：

- 新的窗口置顶和窗口权限诊断套件依赖本版没有的实现，因此未纳入。
- 开发版 domain.test.js 的 3 项断言针对后续的主页卡片排序、保留尺寸与允许空位布局。上游已提交的旧 domain.test.js 又有 1 项要求待办必须设置截止时间，与本版支持无截止时间待办的行为不同。两份 domain 套件均已整份排除；没有改写断言或加入跳过规则。其余相关领域逻辑仍由上述专门套件覆盖，但本仓库不声称领域逻辑全部经过自动化测试。
- 原上游发布工作流及网站测试不对应本仓库的发布方式，未纳入运行时测试。

本次发布命令不使用测试名称筛选或跳过参数。
